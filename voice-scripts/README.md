# Mari's World: voice scripts

One script per family member. Each line has an English and a Portuguese version; record whichever languages you speak. The game uses the computer voice for anything not recorded yet.

## How to record

- Use the iPhone Voice Memos app in a quiet room, phone about 20 cm from your mouth.
- Say each line with a big smile and lots of energy, a little slower than normal. Toddlers love excitement!
- Leave a one-second pause between lines. One long recording per section is fine; it will be cut into pieces later.
- Say the file name before each line (for example "house greet, English") so the pieces are easy to match.
- Send the recordings back and they get added to the game, replacing the computer voice for that person.
